# Sistema de Gestão de Cooperativa de Insumos Agrícolas

# Descrição do Minimundo

Uma cooperativa agrícola fornece insumos como adubos, herbicidas e fertilizantes para seus produtores associados.

O sistema tem como objetivo controlar o cadastro dos produtores, os insumos disponíveis, as compras realizadas e o pagamento anual das mensalidades dos associados.

# Regras de Negócio

* Um produtor pode realizar várias compras.
* Cada compra pertence a apenas um produtor.
* Uma compra pode conter vários insumos.
* Um insumo pode estar presente em várias compras.
* Um produtor pode pagar várias mensalidades ao longo dos anos.
* Cada mensalidade pertence a apenas um produtor.

# Processos Principais

* Cadastro de produtores.
* Cadastro de insumos.
* Registro de compras.
* Controle de mensalidades.
* Consulta de histórico de compras.
